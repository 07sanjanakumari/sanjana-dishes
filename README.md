# 🍴 Sanjana Dishes

A simple and responsive recipe website built using **HTML and CSS**, featuring a collection of delicious dishes with a clean and user-friendly interface.

## ✨ Features

* 🍽️ Browse different dishes and recipes
* 📖 Easy-to-read recipe information
* 🎨 Clean and attractive user interface
* 📱 Responsive design
* 🖥️ Built with HTML & CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📂 Project Structure

```text
sanjana-dishes/
│
├── index.html
├── style.css
├── images/
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/07sanjanakumari/sanjana-dishes.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Purpose

This project was created to practice **frontend development, HTML structure, CSS styling, and responsive web design**.
